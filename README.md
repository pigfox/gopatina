# GoPatina

> A patina is the thin layer that forms on metal: Go on the surface, Rust underneath.

GoPatina is an early-stage, design-stage open-source project exploring a Go
toolchain front end with an opt-in mode that compiles a defined subset of Go to
Rust: no garbage collector, Rust's memory safety, and direct use of Rust crates.

**Status:** pre-alpha. There is no working compiler yet. A design RFC and a
minimal prototype CLI are on the way.
