# The corpus for gopatina-coverage (docs/COVERAGE.md).
#
# Rule: the standard library of the Go toolchain that runs the measurement,
# and 51 widely used open-source Go modules, chosen by the maintainers to
# span what Go is used for (web frameworks, command-line tools, encoding,
# logging, databases, networking, concurrency, the golang.org/x libraries).
# They were chosen by judgment, not from a ranking: no popularity ranking
# was available to the tool reproducibly, and that is a known bias of the
# corpus. "latest" is pinned by `gopatina-coverage resolve`, which writes
# the lock file (version, go.sum hash, commit) the measurement uses.
