# Local verification benchmark runs — 2026-11-18

**Not official.** These are two full runs of `bench/run.sh` on the
maintainer's workstation, not on the dedicated quiet test server required by
[docs/QUALITY.md](../../docs/QUALITY.md#performance-shadow-rust-and-keep-up).
They are published so the numbers in [BENCHMARKS.md](../../BENCHMARKS.md) have
raw evidence, not as release figures.

| Raw results | [run 1](2026-11-18-local-71630d1.json), [run 2](2026-11-18-local-71630d1-repeat.json) |

The commit above is the tree that produced the compiler binaries. The
`suffix-sum` benchmark case and this results directory were added afterwards;
they are test inputs and documentation. A later commit changed only how the
emitted panic hook words runtime panics and marks user panics; none of these
three cases panics, so the timings are unaffected.

| Case | GoPatina / Rust, run 1 | GoPatina / Rust, run 2 | Plain Go / Rust, run 1 / 2 | GoPatina / Go, run 1 / 2 |
| --- | --- | --- | --- | --- |
| `fib` | 0.890 | 1.039 | 2.043 / 1.885 | 0.436 / 0.551 |

| `suffix-sum` | 1.042 | 1.028 | 1.024 / 1.029 | 1.018 / 0.999 |

Worst GoPatina / Rust across both runs: 1.039 (`fib`), 1.043 (`sieve`),
1.042 (`suffix-sum`). All are inside the 1.10 target, but the `fib` spread
(0.890 to 1.039) shows this machine is not quiet enough for official figures.
