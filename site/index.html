GoPatina

A patina is the thin layer that forms on metal: Go on the surface, Rust underneath.

Go developers get Rust's performance and safety without the painful Rust learning curve.

GoPatina is a Go toolchain front end. With no flag it is plain Go, and every existing Go program builds exactly as before. With an opt-in flag, a defined subset of Go compiles through Rust: no garbage collector, ownership and borrowing inferred by GoPatina's own borrow checker, and errors explained in Go terms. You write no Rust syntax, lifetimes or async keywords.

Status: design stage. GoPatina is not a working compiler yet. Today there are the design documents (RFCs) and a prototype command-line tool that passes commands through to Go. The patina modes report "not implemented yet". No benchmarks have been run.

Three modes, two flags

ModeFlagGarbage collectorCompatible with all GoOutput
DefaultnoneYes (Go's)YesA Go binary, built by your installed go (works today)
Emit Rust-emit-rustNoNo: a defined subsetA readable Rust crate you can keep and build with cargo (planned)
Patina-patinaNoNo: the same subsetA native binary built by rustc from that crate (planned)

A third option, -patina=check, is planned to run the same checks and then build with the Go compiler, for machines where Rust cannot be installed.

Try it today

Requires Go 1.25 or later. Without a patina flag, gopatina runs go with the same arguments.

go install github.com/pigfox/gopatina/cmd/gopatina@latest

git clone https://github.com/pigfox/gopatina
cd gopatina
gopatina run ./examples/counter     # prints: total: 4000
gopatina build -emit-rust .         # exits 2: not implemented yet
